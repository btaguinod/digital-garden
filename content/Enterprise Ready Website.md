# Intro

I knew nothing about cloud and infrastructure when I first got my job as a cloud engineer at HPE. At that job, I learned about all the enterprise-scale technology that makes applications scalable and highly-available. My experience there inspired me to start homelabbing, and create this project to learn more about enterprise application infrastructure.

# Purpose

1. To learn
   1. to learn more about enterprise infrastructure
2. To showcase
   1. to demonstrate my infrastructure knowledge

# Stack

This is everything in my stack, from bottom to top
**Hardware:** Mini PC Cluster (HP Elitedesk Mini, i750 Intel CPU, 8GB RAM, 100GB SSD)
**Virtualization Layer:** Proxmox
**Container Orchestration Software:** k3s (Kubernetes)
**Package Software**: Helm
**GitOps Software:** ArgoCD
**Networking**: Cillium
